# ご依頼内容作成ツール

イラストレーターへの制作依頼文を、フォームに入力するだけで簡単に作成できるWebツールです。
依頼者様が迷わずに必要な情報を記入できるように設計しており、生成されたテキストはそのままメールやDMに貼り付けて使用できます。


## ✨ 特徴
* **直感的なフォーム入力**: 必須項目が明確で、記入漏れを防ぎます。
* **ワンクリックコピー**: 生成されたテキストをボタン一つでクリップボードにコピーできます。
* **レスポンシブデザイン**: PC、スマホどちらからでも快適に利用可能です。
* **入力チェック機能**: 必須項目が未入力の場合、アラートでお知らせします。

## 📂 ファイル構成
* `index.html`: フォームの構造とレイアウト
* `style.css`: デザインと装飾
* `script.js`: テキスト生成とコピー機能のロジック

## 🚀 使い方
1.  このリポジトリをダウンロード（Clone）します。
2.  `index.html` をブラウザで開くとツールが起動します。

## 🛠 カスタマイズ方法
ご自身のコミッション内容に合わせて、項目を自由に変更してご利用ください。

* **選択肢の変更**: `index.html` 内の `<select>` タグの中身を編集してください。
* **配色の変更**: `style.css` の `:root` にある変数を変更するだけで、全体の色味を変えられます。

```css
:root {
    --primary-color: #4A90E2; /* メインカラー */
    /* ... */
}
